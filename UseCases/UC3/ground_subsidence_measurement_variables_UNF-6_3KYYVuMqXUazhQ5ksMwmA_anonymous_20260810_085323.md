# Variables to Measure for Ground Subsidence

A measurement schema for assessing ground subsidence associated with shrink-swell and expansive clay soils.

| Variable | Suggested unit |
|---|---|
| Vertical ground displacement | mm or cm |
| Subsidence rate | mm/year |
| Seasonal displacement amplitude | mm |
| Soil moisture / Soil Water Index | m³/m³ or index |
| Rainfall | mm/day or mm/month |
| Evapotranspiration | mm/day |
| Drought severity and duration | index; days |
| Groundwater level | m below ground level |
| Clay content | % |
| Clay mineralogy, especially smectite | % or class |
| Plasticity index | % |
| Liquid limit | % |
| Shrinkage limit | % |
| Coefficient of linear extensibility (COLE) | cm/cm or class |
| Swell pressure / free swell | kPa; % |
| Soil layer depth and thickness | m |
| Soil bulk density | g/cm³ |
| Soil temperature | °C |
| Land cover and vegetation type | class |
| Tree location, species, canopy/height | m; categorical |
| Distance from trees to assets | m |
| Building footprint and foundation type/depth | class; m |
| Building damage condition / crack width | class; mm |
| Location and elevation | latitude/longitude; m |
| Geological formation / hazard susceptibility class | categorical |
| InSAR coherence and measurement uncertainty | index; mm |
